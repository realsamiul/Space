Technical Architecture

Stage 1: Data Ingestion

Real-time ingestion from ESA Copernicus via AWS Ground Station. Sentinel-1 SAR (C-band, VV/VH polarization) provides cloud-penetrating flood detection. Sentinel-2 MSI adds NDWI, NDVI spectral indices during clear-sky windows.

# Sentinel-1 preprocessing pipeline scene = Sentinel1Scene.from_safe(path) scene.calibrate(output='sigma0') scene.terrain_correct(dem='SRTM_30m') scene.apply_speckle_filter('refined_lee', window=7) flood_candidates = scene.threshold_otsu(band='VH')

Stage 2: Foundation Model

Custom Vision Transformer (ViT-Large) with 307M parameters. Pretrained on ImageNet-22k, then domain-adapted on 47,000 historical flood events (2018-2023) from Global Flood Database + Bangladesh FFWC records.

Stage 3: Physics Constraints

Hybrid loss function that penalizes predictions violating Manning's equation for open-channel flow:

L_total = L_BCE + λ₁·L_manning + λ₂·L_gradient + λ₃·L_temporal where: L_manning = ||v_pred - (1/n)·R^(2/3)·S^(1/2)||₂ L_gradient = penalty for water flowing uphill L_temporal = consistency across 6-hour windows

Stage 4: Probabilistic Ensemble

Monte Carlo dropout (N=50) generates confidence bounds. Quantile regression outputs P10, P50, P90 flood extents. Calibrated using reliability diagrams over 2,300 validation events.

Stage 5: Alert Dissemination

Sub-district geofencing triggers SMS via Twilio, WhatsApp alerts, and IVRS (Interactive Voice Response) in Bangla/English. Village-level coordinators receive detailed maps via Progressive Web App.

Technical Appendix

Vision Transformer (ViT) ▼
Neural network architecture treating images as sequences of patches. Each 16×16 pixel patch becomes a token, processed by multi-head self-attention. Excels at spatial context modeling—critical for flood boundary detection.
SAR (Synthetic Aperture Radar) ▼
Active microwave sensor that penetrates clouds and operates day/night. Water surfaces appear dark (low backscatter) in SAR imagery, enabling all-weather flood mapping. Sentinel-1 uses C-band (5.6 cm wavelength).
Manning's Equation ▼
Empirical formula relating channel flow velocity to roughness, hydraulic radius, and slope: v = (1/n) × R^(2/3) × S^(1/2). Used as physics constraint in loss function to penalize unrealistic flow predictions.
DEM (Digital Elevation Model) ▼
Raster dataset representing ground elevation. FloodSight uses SRTM 30m + ALOS 12.5m fused DEM. Elevation gradients determine flow direction; critical for validating that water doesn't flow uphill.
Monte Carlo Dropout ▼
Uncertainty quantification technique. Randomly drops neurons during inference (N=50 runs) to generate prediction ensemble. Variance across runs estimates model confidence—high variance = low certainty.
NDWI (Normalized Difference Water Index) ▼
Spectral index highlighting water: (Green - NIR) / (Green + NIR). Values > 0.3 typically indicate open water. Derived from Sentinel-2 optical bands to complement SAR data during clear weather.
